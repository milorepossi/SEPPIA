## Reading this

- The comparison is **paired**: every arm sees the same five splits. An arm's SD across splits is mostly split difficulty, which is shared, so it swamps the difference between arms. The sign being consistent across all five splits carries the argument, not the means.
- **Single seed per split.** Pooling and standardisation alone move Spearman by about 0.025 on identical information, so a gap smaller than that is not evidence about a representation.
- `pca:20` is the budget-matched comparison: every arm gets exactly 860 features and a byte-identical head. `flatten` gives a PLM arm 55,040 features and 64x the first-layer parameters, so it is a capacity experiment, not a representation one.
- Layer 0 is rank 20 on this alphabet, so `pca:20` is **lossless** for it and arm L0 carries the same information as one-hot. L0 against one-hot is therefore a pipeline check whose expected result is a tie.
